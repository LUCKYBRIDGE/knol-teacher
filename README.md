# 놀티쳐 (KnolTeacher)

교실 수업과 학급 운영을 돕는 Windows 데스크톱 도구입니다.

이 저장소는 놀티쳐의 새로운 공식 개발·배포 기준 저장소입니다. 버전 이력은 v1.0.0부터 새로 시작합니다.

## 기본 원칙

- 학생·학급 정보는 Local-Only를 기본으로 하며, 핵심 기능은 학생 번호만으로 사용할 수 있습니다.
- 공식 배포본은 Windows 10/11 x64용 단일 실행파일로 제공합니다.
- GitHub Release의 배포 파일은 `KnolTeacher.exe`, 사용자 PC에서 사용하는 실행파일 이름은 `놀티쳐.exe`입니다.
- v1.0.0 이후 업데이트는 이 저장소의 GitHub Releases를 기준으로 확인합니다.

## 저작물 및 자산

저장소에 포함된 놀티쳐 전용 이미지·아이콘·레이스 시각 자산은 프로젝트를 위해 제작 또는 생성한 자산을 사용합니다. 사용자용 문서와 업데이트 안내는 놀티쳐 자체의 기능과 사용 경험을 중심으로 설명하며, 외부 제품·서비스를 구현 출처나 유사성의 근거로 제시하지 않습니다.
