# 놀티쳐 (KnolTeacher) v1.0.0

교실 수업과 학급 운영을 돕는 Windows 데스크톱 도구입니다. 이 저장소는 놀티쳐의 공식 개발·배포 기준 저장소이며 제품 버전과 공개 이력은 **v1.0.0부터 새로 시작**합니다.

## 주요 기능
- 타이머, 일정, 알림, QR, 판서 등 자주 쓰는 수업 도구를 한곳에서 사용할 수 있습니다.
- 놀보드 위젯을 배치·이동·크기 조절해 수업 화면을 구성할 수 있습니다.
- 학생 이름을 입력하지 않아도 번호만으로 학생 선택 기능을 사용할 수 있습니다.
- 일정과 주요 설정은 사용자 PC에 로컬로 저장하는 것을 기본으로 합니다.
- 듀얼 모니터 환경에서 지원되는 독립 창을 원하는 화면에 빠르게 열 수 있습니다.

## 개인정보 및 저장 원칙
학생·학급 정보는 **Local-Only**를 기본으로 합니다. 핵심 기능은 학생 번호만으로 사용할 수 있으며 이름 등 개인 정보는 사용자가 선택한 경우에만 로컬 PC에 저장합니다. 학생 정보를 자동으로 외부 서버나 AI 서비스로 전송하지 않습니다.

## 배포와 업데이트
- Windows 10/11 x64용 self-contained 단일 실행파일로 배포합니다.
- GitHub Release asset: `KnolTeacher.exe`
- 사용자 PC 공식 실행파일: `놀티쳐.exe`
- v1.0.0 이후 업데이트는 `LUCKYBRIDGE/knol-teacher`의 최신 Stable Release만 확인합니다.
- 업데이트 파일의 크기, SHA-256, 실행파일 내부 버전을 검증한 뒤 적용합니다.
