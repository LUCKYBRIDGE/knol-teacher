# 놀티쳐(KnolTeacher) UI/UX 디자인 & 레이아웃 가이드라인

Windows 10/11 x64 및 교실 환경(선생님 PC, 학생 전자칠판, 빔프로젝터)에 최적화된 데스크톱 Fluent Design 2 가이드입니다.

---

## 1. 전역 레이아웃 아키텍처 (Studio Left-Sidebar Layout)

```
┌─────────────────┬───────────────────────────────────────────────────────────────────┐
│ 좌측 사이드바   │ 우측 상단 바 (Top Action Dock & Status)                           │
│ (너비: 230px)   │  • 실시간 교시 상태 + 듀얼모니터 감지                             │
│ • 로고 & 타이틀 │  • 빠른 실행 독: [놀보드 F2] [판서] [칠판] [타이머] [뽑기]        │
│ • 6개 메뉴 탭   │  • 유틸리티: [알람 ON] [위젯 편집] [양식 다운로드] [도움말]       │
│ • 핑키네 바로가기├───────────────────────────────────────────────────────────────────┤
│ • 테마 선택기   │ 우측 메인 작업 영역 (MainTabs Content Area)                       │
│   (스튜디오/    │  • Tab 0: 오늘의 일과 & 위젯 대시보드 (캔버스)                   │
│    다크/베이지) │  • Tab 1: 수업 & 교실 실시간 도구 1-Click 그리드                  │
│ • 버전 정보     │  • Tab 2: 스마트 예약 센터 (일정/알림/자동화)                     │
│                 │  • Tab 3: 스마트 데스크 & PC 정리                                 │
│                 │  • Tab 4: 유용한 교육 사이트 & 시도교육청 업무포털                │
│                 │  • Tab 5: 나이스 행동특성/평어 일괄입력 도구                      │
└─────────────────┴───────────────────────────────────────────────────────────────────┘
```

- **너비 기준**: 좌측 사이드바는 230px 고정으로 안정적인 텍스트 라벨과 아이콘을 노출합니다.
- **주 화면 여백**: 메인 캔버스 및 탭 컨텐츠는 마진 `16px`, 내부 패딩 `12~16px`를 유지합니다.

---

## 2. 디자인 토큰 및 색상 시스템

모든 컨트롤은 테마 전환(스튜디오, 다크, 베이지) 시 시인성이 깨지지 않도록 `DynamicResource`를 사용합니다.

| 리소스 키 | 스튜디오(기본) | 설명 |
|---|---|---|
| `BeigeAppBg` | `#EEF2F6` | 메인 윈도우 배경색 (차분한 소프트 그레이) |
| `BeigeSidebarBg` | `#FFFFFF` | 좌측 사이드바 배경색 |
| `BeigeSidebarHover`| `#F1F5F9` | 사이드바 메뉴 마우스 호버 배경 |
| `BeigeAccent` | `#2563EB` | 메인 브랜드/강조 색상 (Royal Blue) |
| `BeigeAccentSoft` | `#EFF6FF` | 활성화된 탭/인디케이터 배경 (Soft Blue Tint) |
| `BeigeCardBg` | `#FFFFFF` | 위젯 및 도구 카드 배경 |
| `BeigeCardInner` | `#F8FAFC` | 카드 내부 섹션/헤더 배경 |
| `BeigeCardBorder` | `#E2E8F0` | 카드 및 구분선 테두리 (1px) |
| `BeigeTextMain` | `#0F172A` | 주요 본문 및 제목 텍스트 |
| `BeigeTextSub` | `#334155` | 보조 설명 텍스트 |
| `BeigeTextMuted` | `#64748B` | 단축키 배지/캡션 텍스트 |

## 3. 타이포그래피 및 교실 시인성

- **글꼴**: `Segoe UI Variable Display, Malgun Gothic, Segoe UI`
- **크기 체계**:
  - 앱 타이틀: `18~19pt Bold`
  - 섹션 제목: `15~16pt Bold`
  - 카드 타이틀: `13~14pt Bold`
  - 본문 텍스트: `12~12.5pt Regular/SemiBold`
  - 보조/캡션/배지: `10~11pt SemiBold/Bold`
- **명도 대비**: 최소 4.5:1 이상을 엄격히 준수하여 프로젝터 투사 시에도 식별성을 보장합니다.

---

## 4. 컴포넌트 인터랙션 및 터치 타깃

- **버튼 규격**:
  - 상단 독 버튼: 높이 `34~36px`, 패딩 `10,5px`, 코너 라디우스 `8px`
  - 사이드바 메뉴: 높이 `42px`, 패딩 `12,0px`, 코너 라디우스 `8px`
  - 도구 카드: 높이 `110~130px`, 마우스 호버 시 미세한 테두리 강조
- **단축키 안내**:
  - 모든 주요 도구는 배지 형태로 단축키(`Alt+2`, `F2` 등)를 명시하여 교사의 빠른 조작을 지원합니다.
